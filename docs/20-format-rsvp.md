# Format: RSVP typography (`OneWord`)

**One word at a time on near-black, held at a fixed anchor, the recognition
letter in the accent colour, synced to a voiceover.**

Component: `motion-graphics/src/AdRsvp.tsx`. It is also the shared scaffold for
every other motion-graphics format: the others add a component next to it and
reuse the same timings, bed, grade and build machinery.

## Why start here

Zero generation spend, no footage, no API key. Reuse the voiceover of an
existing ad and there is no new audio either, which makes it the one honest
format test: same voice, same script, same music, only the presentation moved.
It is the cheapest thing to be wrong about.

## What RSVP is

Rapid serial visual presentation, the Spritz technique. **It is not Bionic
Reading.** Bionic Reading bolds word openings in running text to guide the eye
along a line. With one word on screen there is no line, so that does nothing.

**The whole trick is the fixed anchor.** The recognition letter sits at the
same x on every word and the word is laid out around it, so the eye never moves
and never re-hunts. An early build centred each word instead, which slid the
anchor with word length and brought back exactly the cost RSVP removes. If you
touch `AdRsvp.tsx`, keep the anchor fixed.

## Build one

Run from `motion-graphics/` (`setup.sh` has already installed the packages):

```bash
python3 scripts/bed.py                                   # the music bed, once; run from the engine root
python3 scripts/timings.py brands/<slug>/assets/audio/vo_NNN.mp3 brands/<slug>/assets/words/NNN.json
python3 scripts/prosody.py brands/<slug>/assets/audio/vo_NNN.mp3 brands/<slug>/assets/words/NNN.json
# add one entry to src/configs.mjs, using the voEnd that timings.py printed
./build.sh NNN
```

`voEnd` is the end time of the last word. **Do not guess it.** Too low and the
end card cuts into the read; too high and the ad ends on a held word and
silence. Read the transcript `timings.py` prints: it is your first check that
the voice said the script.

`build.sh` renders both ratios (9:16 and 4:5), named to the convention in
`80-naming-and-delivery.md`, for example:

```
<PREFIX>_101_Beginner_OneWord_CrackedMugs_Tell_FREE_9x16.mp4
<PREFIX>_101_Beginner_OneWord_CrackedMugs_Tell_FREE_4x5.mp4
```

## Assets

The example brand's voiceover (`brands/example/assets/audio/vo_example_free.mp3`)
and its timings (`brands/example/assets/words/101.json`, example ad 101 in
`brands/example/configs.mjs`) ship with the engine, so you can render before
recording anything. The music bed is generated by `scripts/bed.py`: it is
composed in code, so it carries no licensing exposure.

End-card strings (name, button, sublines) come from the active brand's
`brand.json` (`brands/<slug>/brand.json`) through
the active brand's `brand.json`. A PAID cut's last line can end in an accent-coloured price
(`end_card.paidFollowOnAccent`). Re-rendering an old cut prints today's brand
values, not the ones it originally shipped with.

## Making it yours

Nothing in `AdRsvp.tsx` is brand-specific. Name, subline, button, avatar,
palette, anchor and type sizes live in the active brand's `brand.json`. See
`90-make-it-your-own.md`, including the two knobs that silently break the
format if turned the wrong way.

## The files

| File | What it is |
|---|---|
| `brands/<slug>/brand.json` | Start here. Name, end-card copy, palette and the format's visual knobs. The only file a rebrand touches (the active brand's `brand.json` reads it through `scripts/brand.py use`). |
| `src/AdRsvp.tsx` | The format. Its comments record why the anchor is fixed. |
| `src/configs.mjs` | One entry per ad. The only file you edit to add one. |
| `src/Root.tsx` | Compositions, generated from `configs.mjs`; maps a config's `format` to a component. |
| `src/theme.ts` | Re-exports the active brand's palette. |
| `scripts/timings.py` | Voiceover to word timings. Prints `voEnd` and the transcript. |
| `scripts/prosody.py` | Flags uptalk. Does not replace listening. |
| `scripts/bed.py` | The composed music bed. |
| `scripts/grade.py` | The realism pass, for generated footage only. |
| `build.sh` | Renders every ad in `configs.mjs`, both ratios, named to convention. |

The code is not reproduced here on purpose: a second copy in a document drifts
from the one that runs.
